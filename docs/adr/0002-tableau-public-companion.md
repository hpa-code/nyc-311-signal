# Tableau Public companion fed by a CSV export

We add a Tableau Public workbook alongside the Streamlit dashboard, to show Tableau work in the portfolio. Streamlit stays the product: it alone gets the stale-data notice, Risk Queue and Request lookup. Tableau Public cannot connect to Snowflake or refresh a file extract on a schedule, so the workbook is fed by `tableau/export.py`, which reads the current Publication from `APP.PUBLISHED_TABLEAU_DAILY` through the read-only dashboard role (so the export passes the same Publication gate as the dashboard) and writes CSVs that are republished by hand. The workbook is therefore a dated snapshot, and says so. The file leaves the warehouse publicly, so it holds counts only, by day, borough, agency, Problem and channel: no `unique_key`, address or location below borough. Cells under 20 Requests stay in the file and are hidden in the workbook's rate views, because the ticket 09 threshold is about reliable comparisons, not privacy: a count identifies no one. Tableau Cloud would give a live connection and scheduled refresh, but it is paid and needs viewer logins, which defeats a public portfolio piece.
