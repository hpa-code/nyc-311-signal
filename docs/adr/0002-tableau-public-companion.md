# Tableau Public companion fed by a CSV export

We add a Tableau Public workbook alongside the Streamlit dashboard, to show Tableau work in the portfolio. Streamlit stays the product: it alone gets the Publication gate, stale-data notice, Risk Queue and Request lookup. Tableau Public cannot connect to Snowflake or refresh a file extract on a schedule, so the workbook is fed by `tableau/export.py`, which reads the secure view `APP.TABLEAU_DAILY` through the read-only dashboard role and writes CSVs that are republished by hand. The workbook is therefore a dated snapshot, and says so. The view holds counts only (day, borough, agency, Problem, channel): no `unique_key`, address or location below borough, since the file leaves the warehouse publicly. Tableau Cloud would give a live connection and scheduled refresh, but it is paid and needs viewer logins, which defeats a public portfolio piece.
